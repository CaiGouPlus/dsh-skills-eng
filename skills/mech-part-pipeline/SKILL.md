# 机械零件流水线

> 一句话：**先定行程，再按阶段走；每阶段有绿灯判据，过不了就停。**
> 本技能只管"顺序与判据"，具体 API 在 `sw-cad-verified`，资产在 §末索引。

## 0. 30 秒判行程

| 用户给的 | 走哪条线 | 首个动作 |
|---|---|---|
| 一个 `.SLDPRT` + "分析/看看" | **A 分析线**：读 → 层析 → 结构 → 评审 | 先确认文件身份（md5），别读错件 |
| 一个 `.SLDPRT` + "复刻/重建" | **B 复刻线**：读真值 → 出计划 → 建模 → 验收 | 先跑 P1.0（读真值），不读原特征树 |
| "做个 X" / 无文件 | **C 新建线**：计划 → 建模 → 验收 | 先查资产地图有没有模板 |
| "改一下尺寸/加个孔" | **D 改型线**：读现状 → 最小改动 → 回归验收 | 先备份 + 读特征树找驱动特征 |
| "出个图/能不能投产" | **E 交付线**：合规 → 出图 | 先跑 DFM，再出图 |

**判断依据不明确时，先问一句再动手**，不要用"分析"当借口跳到建模。

## 1. 六阶段（所有线共用骨架）

| 阶段 | 做什么 | 绿灯判据（过不了就停） | 主要资产 |
|---|---|---|---|
| **P1 计划** | **读真值四层**（标量/结构/拓扑/微分，§1.1）+ **结论—证据绑定**（六条判据通道，§1.4）+ 剔除过程产物（§1.3）+ 写 `design_plan`，每项带 `conf`（§1.2）与 `fallback` | 每个关键尺寸有**来源**且标了置信度；无 D 级参数当驱动尺寸；真值表四层都有数；**每条量化结论写明由哪条通道的哪个读数支撑** | `vibecad` 的 plan 范式、`manufacturing_rules.yaml` |
| **P2 建模** | 一个特征一件事，按几何→关系→尺寸顺序；**C 级参数所在的特征建完必须单独回验该处**（体积不够，要加切片/孔系） | 每特征后 `ΔV` 与预期差 **<5%**；草图 `status==3`、驱动尺寸 >0、**Fix ≤1** | `sw-cad-verified` §0/§6/§17.1 |
| **P3 验收** | 体积 / bbox / 孔系 / 4 个关键截面 / 视图 | 体积 **≤1%**、bbox 每向 ≤0.2 mm、孔数与孔径全对、截面积差 <3 mm²。**门槛按真值置信度缩放**（§1.2） | 本技能 §3 |
| **P4 合规** | 制造规则 + DFM | 规则表阈值是**带 1.5~3 冗余的保守默认值**，低于阈值 ≠ 不合格，走 §3.2 分级处置；只有"几何不成立/装不进/零厚度"才一票否决 | `manufacturing_rules.yaml` §policy、`design-rule-check` |
| **P5 交付** | 存盘关闭、导 STEP、出图、写笔记 | 文件**已关闭**（无锁）、重开可读、图能看。**倒角/去毛刺/表面处理在这一步体现，建模阶段不强制** | `solidworks-engineering-drawing` |
| **P6 复盘** | 记下本次新踩的坑 | 新坑进了技能或 wiki，不是只停在脑子里 | — |

**P1 不写计划直接建模 = 抽卡。** 事故记录：拿到"复刻"就开写脚本，方向探针试错两轮，M3 孔规格全错（用了 3.0/2.6，规则是 3.4/2.5）。

## 1.1 P1 读真值：四层，缺一层就错得像对的

只读"体积+包围盒"是**一维**的真值，能对上体积而漏掉整片结构。按成本从低到高做满四层：

| 层 | 读什么 | 回答什么问题 | 成本 | 漏掉的后果 |
|---|---|---|---|---|
| **① 标量** | 体积、面积、质量、质心、惯量、包围盒 | 总量对不对 | 秒 | 特征漏建/多建 |
| **② 结构** | 特征树（类型/尺寸/终止条件）、草图线段 | 作者怎么做的 | 秒~分 | 只知结果不知意图，改不动 |
| **③ 拓扑** | 面-边-面邻接、同轴分组、通/盲、连通分量、**通孔计数当 genus** | 孔是通是盲、几处连通、内还是外 | 分钟 | 沉孔+通孔被拆成两个盲坑；通孔数错 |
| **④ 微分** | 体素 / 三向切片面积曲线、最小壁厚分布 | 里面空不空、薄壁在哪、最小壁厚多少 | 分钟 | 内部空腔、薄壁、真实开口全看不见 |

- **③④ 不是"高级选项"，是 P1 的必备项**。判据：真值表里必须出现"通孔数""最小壁厚""三向切片面积曲线"三行。
- ③④ 的具体读法（邻接映射、`V−E+F` 为什么不可用、体素分辨率取法、射线起点陷阱）在 wiki `SolidWorks 读零件：先形状后特征树（通用）` §3/§4，别重写。
- ③④ 同时是**验收的尺子**：拓扑给"孔系"尺子，微分给"截面"尺子。P1 不做，P3 就没有基准可比。
- **最小壁厚**用 `cae\part_read\minwall.py`：切一层 → 把边界线段串成环 → 比"非相邻段对"的最小距离。
  它给的是**板内面内间隙**（孔到边/槽到边/薄壁），不是沿厚度方向的壁厚；绝对值受三角面密度影响，
  擅长"定位哪处最薄"和"两版本谁更薄"，不当合格证。
  **已验证到解析值**（滑槽三站）：z=1.0 → 1.4000（Ø3.2 到顶边 1.4）、z=2.5/z=4.5 → 0.2000（沉孔到顶边 0.2）。
  **踩过的坑**：同环排除条件早先用"间隔 N 段"，对小孔（Ø3.2 周长仅 10 mm）不成立——绕 7 段的两条弦仍只隔 1.2 mm，
  报出假正例 1.21。已改为**按沿环弧长 > 周长/4** 判定，跨环那一支本来就对。

### 1.1.1 壁厚工具的升级路线（**备选，不是待办**；真需要时自己分析、自己写）

现工具只解决"等厚板的面内间隙"。遇到下列情况它就**不适用**，不要硬套，按需升级：

| 触发情形 | 问题 | 升级方案 |
|---|---|---|
| 要给出**0.01 mm 级**的绝对值 | 现有读数受三角面密度限制 | **A 加细剖分**：重导更细的 `GetTessellation`（`MaxFacetWidth` 减半或更小），同一套算法重跑。改一个参数即可；误差随密度快速下降。代价：大件变慢/爆内存（历史记录：0.25 mm 体素 7.1M 面） |
| 件**不是等厚板**（有凸台、型腔、管壁、内部通道） | 面内间隙 ≠ 壁厚 | **B 射线法**：每个面片沿内法向打射线，取首个命中距离 → 真正的壁厚分布，与 DFM 的"最小壁厚"定义一致。代价：要写射线-三角求交 + 空间索引，几百行 |
| 边界**已知是圆弧/直线**（我们的拓扑读数里本来就有圆心半径），且不想动剖分 | 折线化带来的误差 | **C 解析法**：把几何描述接进来，直接解"圆-圆 / 圆-线 / 线-线"最小距离，误差到 1e-6。代价中等：要做弧段参数识别 + 与切片环对齐 |

**选的判据**（别一上来就写 B）：
- 等厚板 + 只要"定位最薄处/比两版谁更薄" → 现工具够了，**别升级**。
- 等厚板 + 要签字级的绝对值 → **A**（最省，改参数即可）。
- 非等厚板 → **B**（只有它给了沿厚度方向的真壁厚）。
- 边界干净、又嫌 A 慢 → **C**。

升级后必须做同一件事：**用解析值标定**（挑 2~3 个能手算的位置，如"孔到直边"、"两平行面间距"），对上才准用。

## 1.2 置信度权重：给每个参数标级，后续一切按最低级走

同一张真值表里的数，可靠性天差地别：体积是内核直接给的，而"这个凸耳高 6 因为作者想留 0.2 余量"是我猜的。**不标级，后面就会把猜测当判据。**

| 级 | 权重 | 来源 | 判据 | 在流程里的用法 |
|---|---|---|---|---|
| **A 双证** | 1.0 | 两条**独立**通道一致（体积↔解析反算、B-Rep↔体素、质量属性↔零件框） | 两路差 <0.1% | 可作验收基准，**可单独支撑"合格"结论** |
| **B 单证** | 0.7 | 单通道直接读出（只读了质量属性 / 只读了 B-Rep / 只读了一次特征参数） | 一次读数 | 可用于建模；**验收时该部位必须有第二把尺子覆盖** |
| **C 反推** | 0.4 | 由几何关系推出（相切/镜像/共线/取整/规则表默认值），文件里没直接写着 | 我能写出推导式 | 建模后必须**回验推导值**（体积 + 该处单独切片）；**不得单独支撑"合格"** |
| **D 猜测** | 0.2 | 读不到、靠常识补 | 无 | 只进"待确认清单"；**不得作驱动尺寸**，必须给 `fallback` |

**三条硬规则：**

1. **短板原则**：一块几何/一条判据的置信度 = 参与它的参数里**最低**那一级。一个 B 级孔位配五个 A 级尺寸，这条孔仍算 B。
2. **判据精度不得超过基准精度**：基准是 B 级（单次读数，重复性可能 0.3%），就不许拿 ±0.1% 去卡。**按级放宽门限**：

   | 基准级 | 体积门限 | 截面门限 | 结论口径 |
   |---|---|---|---|
   | A | ±1% | <3 mm² | 可判"精确匹配" |
   | B | ±1% | <3 mm² + **补第二把尺子** | 可判"匹配"，需注明单证 |
   | C | ±3% | <5 mm² | 只能判"形状方向正确"，不得说"复刻成功" |
   | D | 不判 | 不判 | 记入待确认清单 |

3. **升 A 的唯一路径是双证**，不是"多读几次"。同一接口读三遍还是 B 级。

**设计计划里每项写全三件**：`value` + `conf` + `fallback`。缺 `conf` 的计划不算计划。

## 1.3 特征树里的"过程产物"：作者的设计过程不是设计意图

特征树记的是**生成顺序**，里面混着试错、试算、被否决的方案。**照抄等于把别人的草稿当成品。**

典型过程产物（都是真事）：

| 形态 | 怎么认 | 处置 |
|---|---|---|
| 加了又切（空转对） | 逐特征回放的 `ΔV` 互为相反数，且两者轮廓相同 | 剔除，按净效果建 |
| 被压缩的特征 | `IsSuppressed` | 记录但不建 |
| 草图上只用了一部分轮廓 | 草图面积 ≫ 该特征的实际贡献面积 | 只建被用到的那块 |
| 阵列数比实际多 | 阵列参数 × 实例数 ≠ B-Rep 里数出来的数量 | 按 B-Rep 数量建 |
| 反复改的圆角/倒角叠加 | 同一位置多个 Fillet/Chamfer 特征 | 合成一个，取最后生效的半径 |

**认法只有一个：逐特征回放量体积**（全压 → 逐条解压 → 每步记 `ΔV`/面积/包围盒）。`ΔV≈0` 或互为相反数 = 过程产物。

**效力**：过程产物的参数**一律降为 B 级**，且不得进入"设计意图"描述。剔除后重算的净特征表，才配拿 A 级。

> 实例（滑槽）：6 个实特征里前 3 个是空转（+8179.9 / +1063.1 / −7093.0 = 2150.0 mm³，正好等于一次拉伸）。照抄会白担 7000+ mm³ 布尔运算，还会把"作者试错"误读成"设计要求"。

### 1.3.1 ⚠ 草图线段 ≠ 实体面（最贵的一次误判就是这条）

草图里留着作者的定位线、辅助线、被否决的轮廓；这些线**在实体上不一定是面**。
判据：**面族表（平面按 `(n,d)`、圆柱按 `(轴,R)`）里没有的面，不许当约束面用。**

- 滑槽事故：原零件草图里有一条 `y=28.4` 的线。我把它当"凸耳下沿"算薄壁，得出"槽到边只剩 2.4 mm"的结论——可同一份分析里明明写着"8 组平面里没有 y=28.4"。**有证据却没用，然后拿它编出一条缺陷。**
- 正确做法：任何"两个面之间的距离/薄壁"结论，两个面都必须先在面族表里点得出名字。点不出名字 = 不算。

## 1.4 判据来源是并列的：三把尺子 + 标量 + 渲染图；缺的是「绑定」

读真值不是"四层 + 一个视觉补充"，而是**六条并列、可互相证伪的判据来源**：

| 通道 | 给出什么 | 专门用来反驳 |
|---|---|---|
| 标量 | 体积/面积/质量/质心/bbox | 总量错 |
| 结构 | 特征树、草图线段 | 顺序/意图错 |
| **向量**（面族） | 平面 `(n,d)`、圆柱 `(轴,R)` | **"这里有个面"本身对不对** |
| **拓扑** | 面-边-面邻接、同轴分组、通/盲、连通分量 | 关系错（通/盲、收敛/连续、内/外） |
| **微分**（体素/切片） | 材料占不占、最小壁厚分布 | 局部错（薄壁、空腔、真实开口） |
| **渲染图** | 直接看形状与相对位置 | 认错面、认错关系、数错数量 |

### 本次真正的过失：不是缺"视觉"，是拿到三把尺子的数据却没用它验证结论
- **⑫ 那条 2.4 mm 薄壁**：面族表就摆在那儿，8 组平面里**根本没有 `y=28.4`**——向量通道一句话就能否掉，我却把它当成了实体面。
- **⑬ 那条"零宽度收敛"**：微分通道量 5 个站位就够（2.42→2.88 递增，方向都反），拓扑通道看"同一环上 R17.5 与 R20 的邻接关系"也能否掉。

**所以硬规则是「结论—证据绑定」，不是"多一条通道"：**
> 交付文档里每一句量化结论，必须写明它由**哪条通道的哪个读数**支撑。
> 写不出处名的结论 → 降为"待核"，不许进交付文档。

渲染图完全合法、也常是最快的一条（本次 0.21 mm 就是它量出来的），但它**不替代**向量/拓扑/微分——那三条本来就能抓住上面两个错。

### 渲染图怎么当判据用（不是"看一眼"）
1. **定标**：找已知尺寸当标尺，**至少两条独立标线交叉验证**。滑槽做法：M3 孔中心距 20 mm → 28.505 px/mm；横梁宽 28 mm 复核 → 28.03 mm（误差 0.1%）。不吻合不许往下量。
2. **定位边**：沿行/列取亮度，找一阶跳变峰值；高亮轮廓线通常是 2 px 宽的带，**取带心**，不取带边。
3. **报不确定度**：约 ±0.03 mm。判 0.1 mm 级够用，判 0.01 mm 级不够。
4. **只量能反驳自己的量**：优先量你正要下结论的那几处（薄壁、间隙、孔位），别泛泛量一遍。

## 2. 各线的阶段裁剪

| 线 | P1 | P2 | P3 | P4 | P5 |
|---|---|---|---|---|---|
| A 分析 | 只列"要回答哪几个问题"，但要含拓扑：通/盲、连通分量 | — | 用截面/视图/孔系取证据 | 可选 | 写笔记 |
| B 复刻 | **四层全量 + 真值表 + 置信度；过程产物必须剔除** | 全量 | **必须**（门槛按最低置信度缩放） | 必须：隐患只备案不动手（**禁止优化**） | 必须 |
| C 新建 | 四层全量（无原件时③④改成"自定目标值"），置信度按来源标 | 全量 | 必须 | 必须：**允许 FEA / 拓扑优化**，优化后重跑几何验收 | 可选 |
| D 改型 | 只列改动点，但改动处的拓扑/最小壁厚要查 | 最小 | **回归**（改前/改后对比） | 必须 | 可选 |
| E 交付 | — | — | — | **必须**（含让步单整理） | 必须 |

**复刻线不许优化、新建/改型线才优化** —— 这条区别决定 P4 走"备案"还是"上 FEA"，别搞反。

## 3. 交付六闸门（P3+P4+P5 合并，全过才算完）

| 闸门 | 判据 | 证据 |
|---|---|---|
| 1 有真值 | 比对基准可追溯（图纸/真值表/规则表），**且四层都有数、每项标了 conf** | §1.1 / §1.2 |
| 2 几何 | 体积 ≤1%、bbox 每向 ≤0.2 mm、孔系全对、截面差 <3 mm² | 见下四把尺子 |
| 3 可造 | **规则表阈值是含 1.5~3 冗余的保守默认值**：低于阈值先按 §3.2 分级判"有意取舍 / 需 FEA / 停下问"，不直接判不合格。底孔/过孔规格要对；倒角在出图阶段体现 | `manufacturing_rules.yaml` §policy |
| 4 包齐 | SLDPRT + STEP + 参数 JSON + 评审 JSON + 等轴测预览（非空白） | `review_requirements` |
| 5 图能落地 | 视图齐、尺寸链闭合、关键尺寸带公差、孔表/BOM 与模型一致；**工艺要求（倒角/去毛刺/热处理）在此标注并核成本** | 工程图自查 |
| 6 一致性+文件 | 模型—图—孔表一致；文件已关闭无锁、重开可读 | 交叉核对 |

### 3.1 几何闸门：四把尺子（缺一把都会错得像对的）

| 尺子 | 怎么量 | 判据 | 不过说明 |
|---|---|---|---|
| 体积 | `GetMassProperties2` | 目标 ±1% | 特征漏建/多建/切错方向 |
| bbox | `GetPartBox` | 每向 ±0.2 mm | 轮廓画错/参考面方向错 |
| 孔系 | 圆柱族按 `(轴, 直径)` 分组 | 数量、直径、深度全对 | 孔漏了或规格错 |
| 截面 | 沿 3 轴各切 2~4 层，比面积 | 差 <3 mm² | 局部形状错（体积看不出来的那种） |

> 只有体积对不算过。事故记录：某次复刻体积 +0.61%，但"U 形框 2×Ø5 长孔"漏了、顶部孔少了 1 个——**是两块误差互相抵消**。

## 3.2 合规闸门：规则表是"保守默认值"，不是"生死线"

**先认清规则表的性质**：`manufacturing_rules.yaml` 里每一个数都是**留了余量的经验默认值**，内含约 **1.5~3 倍安全系数**（板厚 4.0、壁厚 3.0、孔边距 1.5D、槽端 R1.5 都是这么来的）。它的用途是"没做分析时的安全起点"，**不是"越过即废"的红线**。

所以判定低于阈值时，不要直接判"不合格"，按下面**三级处置**：

| 情形 | 判据 | 动作 |
|---|---|---|
| **Ⅰ 有意取舍** | 实际值 ≥ 阈值 / 2（仍在安全系数覆盖范围内），且**不受力或低应力**、材料为铝合金/低碳钢、空间或重量确实受限 | **判"可接受"，记录取舍理由**。可以出图 |
| **Ⅱ 需定量** | 实际值 < 阈值 / 2，或该处是主要承力路径，或材料偏脆（铸铁/亚克力） | **上有限元**（静力给应力比 + 变形），必要时**拓扑优化**去料；没算过不许出图 |
| **Ⅲ 停下问** | 几何上根本不成立（零厚度、自交、壁厚趋 0）、装不进、与其他件干涉 | **一票否决**，改几何 |

**判断前必须先问的三个问题**（缺一个就会误判）：
1. **这里受力吗？** 不受力的薄壁（定位边、让位口）和承力薄壁完全不同判法。
2. **什么材料？** 6061 铝合金 0.2 mm 薄壁能铣出来（小刀轻切削），铸铁/亚克力同厚度直接崩。
3. **空间/重量是否受限？** 无人机、机器人末端执行器这类，减重优先级高于规则表的保守值。

**优化升级路径**（Ⅱ 类走这条）：
- 静力有限元：给最大应力、安全系数、变形量 —— 安全系数 ≥1.5 即可放过，不必回到规则表数值。
- 拓扑优化：只对"新建线/改型线"开放，去掉不承载的料。
- **复刻线禁止优化**：目标就是 1:1，原件的隐患只备案不动手，改型另存。

**工艺要求放哪**：倒角、去毛刺、表面处理、热处理都属于**出图阶段**，建模阶段不强制建出来（0.2 倒角建模反而拖慢重建、还容易与相邻圆角打架）。

**工艺清单不是封闭集合**：下面只是常见示例，实际还有线切割 / 激光 / 折弯 / 焊接 / 阳极氧化 / 喷砂 / 热处理 / 攻丝前倒角 / 退刀槽 / 清角等。**以用户给的实际工艺为准，不要拿这张表当全集。**
- 待确认的示例项：去毛刺、边倒角、圆角、沉头 vs 圆柱沉孔、通孔 vs 盲孔、螺纹 vs 压铆、表面处理

**成本：不要自己估，也不要自己列。** 工艺成本随批量、刀具工装、公差等级、二次装夹、材料、供应商起订与排产变化，同一工序可差数倍，任何"拍出来的等级"在真实报价面前都会失效。
- 做法：真到需要做成本取舍时，**直接向用户要真实单价 / 工时 / 历史报价**，再据此比选。
- `manufacturing_rules.yaml` 的 `process_cost` 就是按这个原则留空的（`_values: ask_user`），不要自己往里填数字。
- 没有报价时只能做**非成本**的取舍：能通就不做盲孔、空间够就优先沉头、非装配导向面不必倒角——这些是"工序更少"，不是"更便宜"。

> **误判实例（本次真踩）**：把"M3 沉孔到凸耳上下边只剩 0.2 mm"判成"铣沉孔一定崩边"。实际：机加工这种精度没问题、该处不受力、6061 强度够 —— 属于 Ⅰ 类，应判"可接受 + 记录成本上升"，不该判"崩边"。
> 同理"槽外缘到凸耳下沿 2.4 mm < 3.0"：规则值是保守默认值，2.4 在安全系数覆盖内，空间/重量受限时是有意取舍，不是不合格。
> **教训：拿规则表当生死线，会把大量合法设计判死。判之前先问受力/材料/空间。**

**Ⅰ 类要落成"让步单"，不能只写在脑子里**。本机已有机械可用的字段（`scripts/design_rule_check.py`）：
`{fingerprint 或 ruleId, reason, owner, expiresOn}` —— 命中且未过期的让步单会把该条 finding 退出门禁。
所以 Ⅰ 类的正确产出是**一张带理由、责任人、有效期的让步单**，而不是"我觉得没事"。无让步单的 Ⅰ 类等于没判。
（注意：让步单与风险评分都不替代工程签署，报告始终 `reviewRequired=true`。）

**两条容易混的口径**（别搞反）：

1. **一旦做过应力分析，判据就换成"安全系数 ≥1.5 + 变形可接受"，壁厚数字本身不再是门槛。**
   2.0 的壁算出安全系数 2.2 → 合格；3.0 的壁算出 1.2 → 反而不合格。所以 Ⅱ 类的结论要写"安全系数 = ?"，不要写"壁厚 2.4 < 3.0"。
2. **低于表值在评审语境下 = "需要给理由"，不是"判废"。** 图纸评审问"这里为什么只有 2.4"，答得出受力/材料/工艺就走 Ⅰ；答不出才升 Ⅱ 或改件。

## 4. 停下来判断的信号

| 信号 | 说明 | 动作 |
|---|---|---|
| 同一操作失败 **2 次** | 参数/语义猜错了 | 停，跑方向/映射探针，不要改第 3 次 |
| **拉伸/切除返回空** | 首查轮廓闭合，**不要**先查方向/深度 | 见下行 |
| 草图轮廓 `IsClosed()=false` | 轮廓开环——**这是"特征返回空"的第一嫌疑** | 逐段核对端点；先排除"恰好 180° 的弧"（转向标志失效，弧会画到另一侧）。把它拆成两个 <180° 弧通常修不好，改整圆或改结构 |
| 某特征 `ΔV` 与预期差 >2 倍 | 方向或两侧对称没搞对 | 查 `sw-cad-verified` §6 的 `Sd/Dir` 表 |
| 分析读到的数"太整齐"（如 -25.4） | 很可能是映射/翻转 | 画 1×1 矩形拉伸 1 mm 读 bbox |
| 文件读不到/哈希失败 | 被 SW 占用 | 先 `CloseDoc`，别改代码 |
| 补完草图关系后体积变了 | 关系静默改了几何 | 全定义 ≠ 正确，**必须复量体积/bbox** 才能交付 |
| 真值表里出现 D 级参数 | 它是猜的，不是读的 | 不许当驱动尺寸；要么补读到 C 级以上，要么改结构绕开 |
| 某条判据依赖 C 级参数 | 基准本身不确定 | 结论只能写"形状方向正确"，不许写"复刻成功" |
| 想对复刻件做拓扑优化 | 复刻线的目标是 1:1 | **停**。优化只对新建/改型线开放，改型另存不动原件 |
| 低于规则表阈值就想判"不合格" | 规则表是保守默认值（含 1.5~3 冗余） | 先问受力/材料/空间三件事，按 §3.2 三级处置 |
| 准备写"这里太薄/会崩/不合格" | 这是**解释**，不在任何测量值里 | 先去渲染图上量出 mm 值；量不出就降为"待核"，不许进交付文档 |
| 拿一个面当约束算距离 | 可能是草图里的辅助线 | 回面族表点名字；点不出 = 不算（§1.3.1） |

## 7. 反面案例（都是真事）

1. **方向靠猜**：`FeatureExtrusion2` 的 `Dir` 被旧技能写成"无效"，实为有效；靠偏移面试错 40 分钟。→ 教训：**没测过的参数不许用"同理"带过**。
2. **验收只看体积**：+0.61% 通过，实际漏了 2×Ø5 长孔、少 1 个顶部孔，误差互相抵消。→ 教训：**四把尺子缺一不可**。
3. **资产想不起来**：全程只用 1 个技能，漏掉制造规则表（M3 底孔 2.5 用了 2.6）、孔口倒角、DFM。→ 教训：**P1 必须扫资产地图**。
4. **真值只读了一维**：P1 只拿了体积/面积/包围盒就开工，没做拓扑和微分——直到验收才发现"两侧 R5.5 圆头"到底是通孔还是轮廓圆角，读错就要返工。→ 教训：**四层缺一层，错得都像对的**。
5. **把保守默认值当生死线**：拿规则表的 3.0 壁厚判死一个 2.4 的有意取舍，还预言"铣沉孔一定崩边"。实际铝合金不受力处 0.2 mm 都能做。→ 教训：**判不合规之前先问受力/材料/空间，再按三级处置**。
6. **把别人的草稿当成品**：差点照抄特征树里的"加了又切"空转对，白担 7000+ mm³ 布尔运算。→ 教训：**读树之后必须逐特征回放量体积，剔除过程产物**。
7. **数字全对、理解全错**：体积/面积/质量/包围盒 0.0000%、13 组圆柱逐条相同，却编出两条不存在的"设计缺陷"——拿草图辅助线 `y=28.4` 当成实体面，还把一条越走越**厚**的环带判成"收敛到零宽度"。渲染图一量：一条 0.21 mm 坐实、两条当场撤回。→ 教训：**P1 必须有视觉复核这条独立通道；面族表里没有的面不许当约束面**。
