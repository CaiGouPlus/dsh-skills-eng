# 机械设计优化流程（整机 / 方案级）

> 一句话：**先冻结约束，再按 G0→G6 走；每道门禁读不回数就停；优化一次只动一组变量。**
> 权威内容在 wiki「机械设计优化流程·七阶段与门禁」；本技能只写「怎么调、读什么数、什么时候停」。

## 0. 30 秒判行程

| 用户给的 | 入口 | 首个动作 |
|---|---|---|
| 只有一句话需求 / 想法 | **G0** | 先填五张表，把接口钉死，别急着建模 |
| 有方案 / 草图 / 三维 | **G1 或 G3** | 先核自由度与运动指标，再谈结构 |
| 有设计要「优化」 | **O1 基线** | 先把目标量成一个数，再谈改动 |
| 要选材 / 校核某个件 | **G2** | 先定失效形式与设计准则，不许先套公式 |
| 要出图 / 能不能投产 | **G4 → G6** | 先补公差链；单件建模复刻走 `mech-part-pipeline` |

判断依据不明确时先问一句，不要用「优化」当借口跳过 G0。

## 1. 七阶段执行表

| 阶段 | 调用什么 | 产物 | 门禁（读回什么数） |
|---|---|---|---|
| **G0 需求与接口冻结** | 缺约束时 `ask_user_question`；细则见 wiki「需求分类·四必填与两常有」 | 一页任务书 + 五张表（FR/LC/ICD/KR/OI） | 每条需求可测量且写明测量方法；每个接口有配合+公差+基准；待定项有默认假设且不致返工 |
| **G1 方案与运动综合** | `cae_matlab`（本机 `solve_math` 缺解释器时的兜底）：位置/速度/加速度、传动比、可行域；`mech_diagram`（运动线图） | 方案对比表（≥3）+ 参数表（单一源）+ 极限位图 | 自由度 F = 3n − 2×低副 − 高副，与预期一致；行程/摆角/传动比达标；≥3 方案排序；敏感度 top-3 |
| **G2 零件设计与材料** | `mech_analyze`（轴/梁内力、应力、挠度）；`cae_matlab` / `solve_math`（齿轮/轴承/螺栓公式）；`engineering-mechanics` 技能 | 计算卡（每件一行）+ 材料表（材料/热处理/毛坯） | 安全系数、轴承 L10、挠度有数；[σ]、[τ] 与材料+热处理同源；许用值有出处，并注明**适用零件与工况** |
| **G3 结构与装配** | `sw-cad-verified`（SolidWorks）；DOF 账本；干涉数值化 | 零件 + 装配体 + 配合清单 + DOF 账本 + 干涉报告 | Σ剩余DOF = 关节数×1；每件体积/包围盒/质心与手算一致；干涉数 = 预期值；`null` ≠ 0 |
| **G4 互换性与公差** | `solve_math` / `cae_matlab`（公差链极值法/概率法）；wiki 互换性章节 | 公差链表 + 配合表 | 链闭合（Σ增−Σ减＝封闭环，含公差）；关键配合有代号+数值；形位有基准；量具分辨力 ≤ 公差/10 |
| **G5 制造工艺与装配** | `manufacturing_rules.yaml` + `design_rule_check.py`；三级处置 | 工艺卡 + DFM 报告 | 每个特征有可行工艺；无不可造几何；装配顺序无「装不进」；倒角/去毛刺/热处理在此标注；**规则表只覆盖板件**，回转体/螺纹件用工艺性清单 |
| **G6 制图与交付** | `solidworks-engineering-drawing` 技能 | 图纸 + BOM | 尺寸链闭合；关键尺寸带公差；粗糙度与公差等级匹配；BOM 与模型一致；图能照着造 |

**一次只推进一个阶段**；阶段之间给产物与读数，不连跑。

## 2. 优化闭环协议（贯穿 G1–G6）

| 步 | 做什么 | 纪律 |
|---|---|---|
| O1 基线 | 把目标量成一个数（kg / 元 / mm / h），记下当前方案 | 没有数不许开始「优化」 |
| O2 变量·目标·约束 | 列设计变量（含区间）、目标函数、约束集合 | 变量只取 B/C 级来源的可动区间；**A 级外部硬约束禁改** |
| O3 敏感度 | 每个变量 ±5% 扰动，按 S = (Δf/f) ÷ (Δx/x) 归一化排序 | 只动 top-k；先确认它不是被约束卡死的 |
| O4 定向改进 | 一次只改**一个强耦合组**，其余冻结 | 同时动两个强耦合量＝无法归因 |
| O5 复算 | 回受影响阶段重跑门禁 | 改材料→G2；改公差→G5；改结构→G3；改方案→G1 |
| O6 收敛 | 相对改进 < 1% 连续两轮 / 触约束边界 / 连续两轮无可行改进 | 停，不要「再试试」 |

**多目标**（重量/成本/寿命/效率）：先出 Pareto 前沿，再由人定权重。**不许**把两个目标揉成一个「综合评分」糊过去——那是在藏取舍。

**敏感度怎么算才可复现**：固定其余变量 → 变量取 +5% 与 −5% 各跑一次 → 取平均斜率 → 除以基线目标值归一化。单侧算不出（不可行域）就记 `∞`，说明它已被约束卡死。

## 3. 运行环境（2026-11 实测，改环境前别忘）

- **`solve_math` 不可用**：本机缺 numpy+PIL 解释器，调用直接报错。数值计算用 `cae_matlab` 兜底（启动 ~15 s，适合一次算完多项）。
- **材料许用值分散**：库里没有集中材料数据页，许用值散在概念笔记中，口径不一（轴瓦 [p] ≈ 15 MPa ≠ 螺母比压）。引用时写清零件与工况，否则按 C 级假设处理。
- **DFM 规则表只覆盖板件**：`manufacturing_rules.yaml` 的壁厚/孔边距/底孔/倒角都是板件口径；回转体、螺纹件另查工艺性清单（细长比、退刀槽、螺纹收尾、中心孔、装夹基准）。
- **制图门禁不能自动判**：降级为「图样三查」检查单，写清是检查单，不是数值门禁。

## 4. 停车信号

- 门禁读不回数（`null` / 空数组 / 异常返回）→ **未通过**，不许当 0
- A 级外部约束在优化中被动了 → 回 G0 登记，不许就地改
- 同一道门禁失败 2 次 → 换方法或问人，不要改第 3 次
- 材料 / 标准 / 许用应力无来源 → 标 C 级假设，写「待核」，不许当结论
- 想跳过 G4 直接出图 → 停：公差是制图的前置
- 想对复刻件做拓扑优化 → 停：复刻目标是 1:1，优化只对新建/改型开放
- 用户说「应该没问题」→ 换成可测量的判据，否则记为未通过

## 7. 交付口径

每个阶段结束时给三样：**产物**（表/图/数）、**门禁读数**（过了哪条、数是多少）、**未决项**（谁定、什么时候定）。
不写「应该没问题」「基本满足」——写不出数的结论一律降级为「待核」。
