# 零件几何理解：三种表示与执行顺序（v0.1 · 案例版）

> 通用方法论已抽成《零件几何理解·通用方法论》v1.0（`零件几何理解·通用方法论.md`）；本文保留为轴承座案例的实测记录。

> 本文理清“读一个零件”的当前方法：向量、拓扑、体素三种表示各自干什么、按什么顺序做、怎样互相校验、还有什么可优化。
> 实测样本：`转向内圈轴承座.SLDPRT`（SW2021，SW2026 打开），以及此前的 `拖链挡板-3d打印.SLDPRT`。

---

## 0. 一句话结论

**向量保精度，拓扑保连接，体素保材料分布。三者不是流水线，而是三角校验。**

默认执行顺序可以写成：

```
框架（单位/轴/包围盒）
  → 向量（面 (n,d)、圆柱 (a,p,r)、族与间距）
  → 体素（0.2–0.3 mm 快速全局：材料在哪、是不是薄壁、通/盲）
  → 拓扑（面-棱-面图、凸凹、边环 → 孔/凸、通/盲的定论）
  → 分段（同面归组 + 连通 + 签名 → 几何版特征树）
  → 校验（体积/面积/欧拉/壁厚/对称，三种表示互证）
```

但这个顺序**不是必须的**：入口由问题决定（见第 4 节）。真正的规则是——**任何一步的结论，都要用另一种表示的独立测量去证伪一次**。

---

## 1. 三种表示各回答什么

| 表示 | 回答的问题 | 精度 | 成本 | 盲区 |
|---|---|---|---|---|
| **向量** 面 `(n,d)`、圆柱 `(a,p,r)` | 尺寸、壁厚、槽深、孔距、平行/同轴、三瓣角度 | 精确（浮点级） | 低（读面参数即可） | 不知道材料在哪一侧；孔还是凸分不出 |
| **拓扑** 面-棱-面图、凸凹、边环 | 内外、凸/凹、通/盲、面归属、特征边界 | 精确（离散） | 中（要建图、判凸凹） | 不给尺寸；环方向处理易错 |
| **体素** 0.2–0.3 mm 占位网格 | 材料分布、薄壁/实心、连通域、整体形状、壁厚图 | 近似（阶梯误差） | 中（几百万体素，秒级） | 尺寸有 ±h 误差；小孔受分辨率限制 |
| **分段**（几何版特征树） | 这是什么特征（孔/坑/台阶/圆角） | 依赖前三者 | 高 | 规则复杂，通用件难 |

## 2. 本轮实际流程（轴承座）

1. **框架**：包围盒 63.5 × 27.4 × 63.5 mm；60° 面/孔阵列以 Y 为轴。
2. **向量**：68 面 = 28 平面 + 37 圆柱 + 3 锥面。
   - 平面族：Y 向 6 个高度（−8.9/−1.5/0/7.8/8.5/18.5）；**三向 120° 平面，内切半径 25/26**（面宽 25.2 = 2√(28²−25²)，一致性通过）。
   - 圆柱：R31.75 / R30 / R29.5 / R28（同轴）、R2.75/2.8 ×12、Ø3 ×15、Ø2.5 ×3（带 118° 钻尖）。
   - 体积 12,535.5 mm³、面积 12,332.5 mm² → 平均厚度 `2V/A ≈ 2.03 mm`（薄壁）。
3. **体素**：228,410 个三角面 → 0.25 mm 网格（254×110×254 = 7.1M）→ 射线奇偶填充。
   - **体积 12,594.8 vs 12,535.5，误差 +0.47%** ✓
   - 切片显示：**薄壁环 + 大内孔**，不是实心。
4. **面朝向**（体素 + 圆柱向量）：R28 三面 = bore 且两端无料 → **Ø56 贯通内孔**；外表面 R29.5/R30/R31.75 = boss。
5. **通/盲**（沿轴射线）：12 个圆坑全 blind；Ø2.5 两个 blind、一个存疑；Ø3 一个 through，其余 blind/受阻。
6. **未做**：拓扑图（边-面-凸凹）、分段、精确截面。

## 3. 每步的输入/输出/校验/失败模式

| 步 | 输入 | 输出 | 校验 | 失败模式 |
|---|---|---|---|---|
| 框架 | 文档 | 单位、轴、bbox | bbox 与面盒一致 | 单位错（mm/m） |
| 向量 | B-Rep 面 | 面族、间距、同轴组 | 弦长/间距恒等式（如 25.2） | `PlaneParams` 符号≠外法向 |
| 体素 | 三角面（`GetTessellation`） | 占位网格、切片、体积 | 体积 vs SW ±1% | 网格不水密、奇偶异常列、分辨率不足 |
| 拓扑 | 面/棱/顶点 | 邻接图、凸凹、边环 | 欧拉 `V−E+F` | 环方向、相切棱 |
| 分段 | 前三者 | 特征表 | 与特征树对账 | 规则覆盖不全 |

## 4. 顺序：为什么不是“先向量、后拓扑、最后体素”

三个表示**互相不知道对方的信息**：

- 向量不知道材料在法向的哪一侧（R28 是孔还是轴，平面内切 25 是削掉还是凸起）——它只说“这里有个面”。
- 拓扑不知道尺寸（能说“这个孔是通的”，说不出 Ø3×10）。
- 体素不知道精确尺寸（0.25 mm 阶梯），也不知道哪个面属于哪个特征。

所以正确做法是**按问题选入口，再交叉证伪**：

| 你想知道 | 先做 | 再用什么证伪 |
|---|---|---|
| 壁厚、槽深、孔距 | 向量 | 体素体积/切片 |
| 孔还是凸、通还是盲 | 拓扑（边环邻接） | 体素射线/切片 |
| 整体是什么形状 | 体素切片 | 向量面族 |
| 这是什么特征 | 分段 | 特征树 |

本轮因为问题集中在“是不是薄壁、内孔还是外圆”，实际走的是 **向量 → 体素**（拓扑还没做），效果已经够回答主要问题；但“通/盲”里那些“两侧受阻”的孔，正是没做拓扑的代价。

## 5. 可优化项（按收益/成本排序）

### 5.1 分辨率策略（收益最高）
- 体素边长 `h` 由**最小特征**定，不是固定值：`h ≤ 最小孔径/5`（Ø2.5 → 0.5 mm 勉强，0.25 mm 可靠）。
- 1e-3 级细节不要用均匀网格（体素数立方爆炸），用**窄带/八叉树**：只在表面附近细分，等效 0.05 mm，体素数只随表面积增长。

### 5.2 体素化算法
- 现在：射线奇偶 + 逐三角形扫描（57/13,730 列奇偶异常，靠丢弃处理）。
- 改进：**有符号距离场（SDF）**或绕数（winding number）代替奇偶；奇偶异常列用顶点扰动或双精度 tie-break；用 `scipy.ndimage.label` 做连通域。

### 5.3 面朝向（当前最大的不确定源）
- 不要用 `PlaneParams` 符号（不等于外法向），也不要用 `IFace2.Normal`（本机读回 0,0,0）。
- 用**每个 facet 自带的法向**（`GetVertexNormal`）或 **SDF 符号**；采样偏移取 `0.5h < d < 壁厚/2`，否则薄壁上会落到同一侧（本轮 55/68 面因此判不准）。

### 5.4 通/盲判定
- 射线法依赖“孔心估计”，斜孔/短孔容易“两侧受阻”。
- 改用**拓扑**：圆柱面的两个端边环各邻接什么面（外表面 / 平面底 / 另一孔）→ 通、盲、交孔一目了然；射线法只做交叉验证。

### 5.5 凸凹与分段
- 凸凹判据：`sign((n₁×n₂)·t_edge)`，棱方向要统一（用环的走向）。
- 分段：同面归组（同 `(n,d)` / 同轴同径）→ 连通合并 → 按签名分类（孔/凸/坑/台阶/圆角/倒角）。

### 5.6 校验项（建议固化成清单）
1. 体素体积 vs `GetMassProperties2`（±1%）；
2. 表面积 vs 体素表面积（±2%）；
3. 欧拉示性数 `χ = V − E + F`（闭合实体应为 2 − 2g）；
4. 壁厚图（SDF 的 2 倍）；
5. 对称性：三向 120°、六向 60° 是否真的均布。

### 5.7 工程与数据
- 不要用 `SaveAs` 导 STL：本机实测有整体平移、体积算成负值。用 `IBody2.GetTessellation()` 直接 dump（本轮 228k 三角面，23 MB）。
- `MaxFacetWidth` 取 `≈ h/2`；过密（1.3M 面）对 0.25 mm 体素没有意义。
- 占位网格用位压缩（`np.packbits`），7M 体素从 7 MB 降到 <1 MB。

### 5.8 复用
- 把 `TesselDump.cs` + `voxelize_seat.py` 参数化（输入路径、h、包围盒），做成 `part_reader` 工具；向量、拓扑、体素三个 dump 共用同一套面编号，保证交叉引用不串号。

## 7. 已知坑（本轮踩到的）

1. `ISurface.PlaneParams` 法向符号 ≠ 面外法向（两个端面都读成 +y）。
2. `IFace2.Normal` 读回 (0,0,0)，不可用。
3. `IFeature.SetSuppression2` 返回 True 但静默不生效，要用 `SetSuppression`。
4. `ISketchSegment` 没有 `GetStartPoint2`（在 `ISketchLine`/`ISketchArc` 上）。
5. SW2026 切除特征类型名是 `ICE`，不是 `Cut`。
6. `GetDepth` 在贯穿/到下一面时返回 0。
7. 圆 = 合并端点的圆弧（起点=终点）。
8. `SaveAs` 导 STL 会带整体平移/负体积；改用 `GetTessellation`。

## 8. 下一步（建议顺序）

1. **拓扑 dump**：面-棱-面邻接 + 每个 facet 的法向 → 定死“通/盲/交孔”。
2. **SDF**：把体素换成有符号距离场，顺带得到壁厚图。
3. **分段**：面片归组 + 凸凹 → 几何版特征树。
4. **校验清单**固化成脚本，任何新零件先跑一遍。

## 更正（2026-11，按用户提供的实物渲染图）

1. 12 个 R2.75/R2.8 不是“盲坑”，而是**Ø5.5 沉孔**；与 R1.5（Ø3）同轴，组成 **12 个径向沉头通孔**（上下两层各 6，60° 均布）。
2. `V−E+F=−6 → g=4` 不可信：闭合圆边无顶点，B-Rep 不是合法 CW 复形。按同轴分组数出的通孔 ≥12，g≈16。
3. 体素射线判“通/盲”出错的原因：起点 `c−radial·r` 落在材料里，输出“两侧受阻”。正确起点应在孔内空气中（轴线 + 沉孔底位置）。
4. `GetEdgeCount=125`，但导出只有 72 条——闭合边无顶点被跳过；边仍带邻接信息，不能被丢弃。
