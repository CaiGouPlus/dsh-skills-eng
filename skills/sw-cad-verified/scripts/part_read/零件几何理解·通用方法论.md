# 零件几何理解：通用方法论（v1.0）

> 适用对象：任意单一实体零件（`.SLDPRT` / STEP / 网格），目标是产出一份**可核对、带证据、带置信度**的几何描述。
> 不依赖零件名、行业、特征树；特征树只作对账，不作依据。
> 案例见《零件几何理解·方法.md》（轴承座：向量→体素实测）与《拖链挡板-客观数据拆解.md》。

---

## 0. 产出契约

一次“读懂”必须交付四样东西，缺一不可：

1. **面族表**：法向族/圆柱组、偏移、间距（尺寸的证据）。
2. **特征表**：类型、参数、位置、方向、证据（面 id + 测量值 + 验证方式）、置信度（高/中/低）。
3. **校验记录**：体积、面积、欧拉数、壁厚、对称性、跨通道一致性。
4. **存疑清单**：哪些结论没定死、卡在哪一步、需要什么才能定。

**规则：没有证据的行不进特征表；冲突未解决的，标“存疑”，不许圆。**

---

## 1. 四种表示与分工

| 表示 | 回答 | 精度 | 成本 | 盲区 |
|---|---|---|---|---|
| **向量** `(n,d)`、`(a,p,r)` | 尺寸、壁厚、槽深、孔距、平行/同轴、角度 | 浮点级 | 低 | 不知材料在法向哪侧；孔/凸不分 |
| **体素** 占位网格 | 材料分布、薄壁/实心、连通域、整体形状、壁厚图 | ±h | 中 | 尺寸有阶梯误差；小孔受分辨率限制 |
| **拓扑** 面-棱-面图 | 内外、凸凹、通/盲、面归属、特征边界 | 精确 | 中 | 不给尺寸；环方向易错 |
| **分段** 几何版特征树 | 这是什么特征（孔/坑/台阶/圆角） | 依赖前三者 | 高 | 规则复杂，通用件难 |

三者关系：**向量保精度，体素保材料，拓扑保连接；分段是结论。** 任何一步结论都要被另一种表示独立证伪一次。

**向量是“眼睛的摘要”，不是眼睛本身**：定长 16 维描述子（`log V`、`log A`、归一化三边、填充率、`A/V^(2/3)`、7 bin 面积加权法向直方图、平面/圆柱面积占比）只给“整体印象”，对“12 个 60° 均布径向孔”这类结构完全无感——7 个 bin 装不下 12 个方向。
要真的“看”，靠的是**族表示**（平面族 `(n,d)`、圆柱族 `(轴, 半径)`）+ **正投影/切片**：轴的**方向分布**是唯一能一眼读出“均布孔系”的量。定长向量只用于相似度检索，且必须 z-score 后再算距离（原始余弦会退化到 0.99）。

## 2. 执行顺序（默认 + 决策树）

### 2.1 默认顺序

```
0 框架：单位、轴、包围盒、主方向
1 向量：面族、间距、同轴组
2 体素：0.2–0.3 mm 全局占位，切 3–6 刀
3 拓扑：邻接图、凸凹、边环
4 分段：同面归组 → 连通 → 签名分类
5 校验：六个质量门（第 5 节），不过就回退
```

体素放在拓扑之前，是因为它几秒钟就能回答“薄壁还是实心”——**先排除错误假设，再做贵的连接分析**。

**第 1–4 步都在看外形**，只是三把尺子轮流上：**向量**（面代数/族：方向、层、半径谱）、**拓扑**（面怎么连成壳：通/盲、凸/凹）、**微分**（体素：材料占不占、薄壁）。三者互为证伪——向量说"这里有个 Ø3 圆柱面"，拓扑说"两端开口就是通孔"，微分说"沿轴抽样确实空着"。缺一把，错得都像对的。

**这条链上没有特征树**：它是对账工具，永远排在形状之后（见 2.2 末行）。理由两条——① 形状数据都在 B-Rep 里，不走特征树就能拿到；特征树要先过 `ICE` 命名、Folder、Suppressed 一堆坑。② 人也是先扫一眼轮廓、数一眼孔，再凑近看结构；先树后形是反着来的。

**但别把「形状优先」当教条**：几何简单、特征却很多（平板 + 阵列孔、镜像、系列零件）时，定长向量几乎没有信息量，直接读树更快。判据是**信息密度 = 几何复杂度 ÷ 特征数**：高 → 形状优先，低 → 树优先。

### 2.2 入口按问题定（不必从头跑）

| 问题 | 入口 | 证伪 |
|---|---|---|
| 壁厚/槽深/孔距 | 向量 | 体素体积 |
| 孔还是凸、通还是盲 | 拓扑 | 体素射线 |
| 整体是什么形状 | 体素切片 | 向量面族 |
| 这是什么特征 | 分段 | 特征树对账 |

### 2.3 回退规则

两路结论冲突时，**先怀疑当前步的隐含假设**，按序排查：
单位 → 法向符号 → 网格水密 → 分辨率 → 判据阈值。仍冲突则标“存疑”，不许取平均。

## 3. 参数选择规则（通用）

| 参数 | 规则 |
|---|---|
| 体素边长 h | `h ≤ 最小特征/5`，且 `h ≤ 0.5×最小壁厚`；Ø2.5 孔 → 0.5 mm 勉强、0.25 mm 可靠 |
| 1e-3 级细节 | 不用均匀网格（体素数立方爆炸），用**八叉树/窄带**（表面附近细分） |
| 网格化 | `MaxFacetWidth ≈ h/2`；过密无意义 |
| 面朝向采样偏移 d | `h < d < 壁厚/2`；太近会落到同一体素，太远会穿墙 |
| 平行判据 | `|n₁·n₂| > 0.999` |
| 同轴判据 | `|a₁×a₂| < 0.02` 且轴线距离 `< 0.02 mm` |
| 间距容差 | 1e-3 mm（读数是浮点，别用 ==） |
| 体积校验 | 体素 vs 内核 ≤ 1% |
| 面积校验 | 体素表面积 vs 内核 ≤ 2% |

## 4. 判据库

### 4.1 向量层
- 平面 `n·x = d`，`d = n·p`；符号统一（首个非零分量取正）。
- 平行面间距 `|d₁−d₂|`；弦长恒等式 `2√(R²−d²)` 用来验证“平面确实削在某个圆柱上”。
- 圆柱同轴、锥/环/球用于倒角/圆角识别。

### 4.2 体素层
- 占位：射线奇偶或 SDF；体积/表面积对账。
- 切片：沿主方向 3–6 刀，看环/实心、壁厚、开口。

### 4.3 拓扑层
- 边→两面（`IEdge.GetTwoAdjacentFaces2`）；面→边环（`IFace2.GetFirstLoop`）。
- 凸凹：`sign((n₁×n₂)·t)`，棱方向用环走向统一。
- 通/盲：圆柱面两端边环各邻接什么面——外表面=开口、平面底=盲、另一圆柱=交孔。
- 孔/凸：面法向 vs 半径方向（facet 法向，不用 `PlaneParams` 符号）。

### 4.4 分段层
- 同面归组（同 `(n,d)` / 同轴同径）→ 连通合并 → 签名分类：
  - 圆柱+两端环+底 → 盲孔；两端开口 → 通孔；
  - 平面底+侧壁环+圆角 → 凹坑；
  - 窄条+两侧相切 → 圆角/倒角；
  - 同径同轴阵列 → 孔系（查角度/间距是否均布）。

## 5. 质量门（六项，全过才叫“读懂”）

| 门 | 判据 | 不过时回退到 |
|---|---|---|
| G1 体积 | 体素 vs 内核 ≤ 1% | 网格/单位/分辨率 |
| G2 面积 | 体素表面积 vs 内核 ≤ 2% | 网格/分辨率 |
| G3 通孔数 | 同轴分组 + 端环邻接数出的通孔数 = 声明的 genus + 1（**不要用 `V−E+F` 反推**：闭合圆边不是 CW 1-cell，实测偏 12 个孔） | 拓扑/分段 |
| G4 截面 | 截面面积沿轴积分 = 体积（±2%） | 体素/截面 |
| G5 对称 | 声明的 120°/60° 阵列在坐标上确实均布 | 向量/取样 |
| G6 跨通道 | 向量尺寸 vs 体素实测差 ≤ 1 体素 | 对应步骤 |

## 6. 可优化项（按收益/成本排序）

1. **SDF 替代射线奇偶**：消除奇偶异常列（本轮 57/13,730），顺带得到壁厚图。
2. **窄带/八叉树**：等效 0.05 mm，体素数只随表面积增长；是做到“1e-3 级细节”的唯一现实路径。
3. **面朝向改用 facet 法向 + SDF 符号**：`PlaneParams` 与 `IFace2.Normal` 都不可靠（本轮 55/68 面判不准）。
4. **通/盲改拓扑边环**：射线法依赖孔心估计，斜孔/短孔会“两侧受阻”；拓扑一次定死。
5. **分段规则化**：同面归组 + 凸凹 + 签名，产出几何版特征树，与历史树对账。
6. **位压缩**：7M 体素从 7 MB 降到 <1 MB；`scipy.ndimage.label` 做连通域。
7. **工具化**：向量/拓扑/体素三个 dump **共用一套面编号**，保证交叉引用不串号；参数化输入路径、h、包围盒。
8. **回归集**：选 5–10 个已知答案的零件（薄壁、轴、齿轮、法兰），任何改动先跑回归，防止“对了一个、错了九个”。
9. **报告自动化**：特征表 schema 固定（id/类型/参数/位置/证据/置信度），生成 md + 切片图。

## 7. 失败模式与对策

| 现象 | 真因 | 对策 |
|---|---|---|
| 体素体积偏差大 | 网格不水密 / 单位错 / 分辨率不足 | 先查 G1，再查网格导出方式 |
| 面朝向大面积模糊 | 采样偏移 ≈ 体素尺寸；薄壁 | 用 SDF 符号或 facet 法向 |
| 孔“两侧受阻” | 射线从孔心出发撞到邻壁/斜交 | 改用边环拓扑 |
| 平面族 d 值重复 | 法向符号未统一 | 规范符号 |
| 圆柱 R 分组碎 | 浮点分组 | 按 0.05 mm 或相对容差聚类 |
| 特征数对不上历史树 | 历史树有删改/所选轮廓 | 以几何为准，树仅对账 |

| id | 类型 | 参数 | 位置/轴向 | 证据 | 置信度 |
|---|---|---|---|---|---|
| F1 | 盲孔 | Ø3×10 | (x,y,z), 轴 +Z | 圆柱面 #12 + 平面底 #13；体素射线 hits | 高 |

置信度规则：两路独立验证=高；单路+一致=中；仅一路或冲突=低（进存疑清单）。

## 10. 边界

- **读得出**：形状、尺寸、连接、特征类型、材料分布。
- **读不出**：设计意图、删除历史、真实材料/公差、装配配合（需装配体）、自由曲面的精确解析（只能采样）。
- 曲面件：平面族退化为“曲面片”，判据换成曲率/边界，本文不覆盖。
