# SolidCraft 数值可信度（0.30.1 实测）

用这张表定**对拍容差**，别拍脑袋。官方 `reference.md` 的 "Reading measure" 说的是同一件事：
解析与实测差 0.001–0.01% 视为一致，**又长又浅的圆弧约 0.1%**（R1000 跨 20°）。

## 体积

| 对象 | 实测 | 相对误差 |
|---|---|---|
| 长方体 100×100×100 | 1,000,000.000000 | **0（精确）** |
| 圆柱 d100×100 | 785,309.5418（精确 785,398.1634） | −1.128×10⁻⁴ |
| 圆柱 d271.3608×60 | 3,469,827.5635（精确 3,470,046.9718） | −6.323×10⁻⁵ |
| 4 弧齿槽轮廓棱柱（h=60） | 2,488.0245（格林 2,486.1869） | **+7.4×10⁻⁴（偏高）** |
| 齿槽轮廓棱柱（h=62） | 2,571.13（A=41.4364 → 2,569.06） | +8.1×10⁻⁴ |

**规律**：多面体精确；圆柱偏小；**含浅弧的截面棱柱偏大**，且量级正好落在官方说的 0.1% 以内。
同一个圆柱换个直径，相对误差会变（d100 −1.1e-4、d271 −6.3e-5），所以**不要用一个标定系数去校正所有尺寸**。

## 面积（草图轮廓）

| 对象 | SolidCraft | 参考值 | 相对差 |
|---|---|---|---|
| 4 弧齿槽（z=104, mₙ=2.5, β=12.4394°） | 41.4364 | SW 沿弧采样 41.4369 | 1.2×10⁻⁵ |
| 腰形槽 L150 W100 | 12,853.9816 | 解析 12,853.9816 | 0 |

**结论：轮廓面积是最可靠的判据**（比体积可靠一个量级），优先用它做交叉验证。

## 怎么复现

```bash
python scripts/probe.py --exe <cli> --work <dir> --selftest
# [1] box 100^3 精确  →  [2] 圆柱落在底噪  →  [3] 腰形槽面积  →  [4] 反向错误可读
```
