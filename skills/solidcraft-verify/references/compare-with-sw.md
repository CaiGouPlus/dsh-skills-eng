# 与 SolidWorks 对拍：同构造才有意义

对拍失败最常见的原因**不是内核分歧，是两边构造不同**。先对齐构造，再谈容差。

## 一、两边各取什么数

| 量 | SolidWorks（C# + PIA） | SolidCraft |
|---|---|---|
| 体积 | `IPartDoc.GetMassProperties2(1, out st, false)[3]`（m³ → ×1e9 得 mm³） | `measure {"summary":true}` → `total.volume_mm3` |
| 外形 | `GetPartBox(true)` | `measure` → `bodies[].bbox` |
| 质心 | 同一 `GetMassProperties2` 的第 0–2 位 | `bodies[].center_of_mass`（`summary` 不含，要去掉 `summary`） |
| 面数 | `IBody2.GetFaceCount()` | `bodies[].faces`（比 `kernel.faces` 更接近逻辑面数） |
| 圆柱/孔 | 遍历面找 `Cylinder`，读半径与轴 | `body_topology {"faces":"cylinders"}`（几行，含 `radius/origin/axis/extent`） |

**单位陷阱**：SW 的 `SystemValue` 是**米、弧度**，体积是 m³；导出时 ×1e9。角度 ×1000 会变成"弧度数值"，别当度用。

## 二、构造必须一致（三个实际例子）

1. **斜齿**
   - SW 参考件：终止草图整体**平移** 12.915 mm，然后放样切除。
   - SolidCraft 复刻：也要平移 12.915（**连圆心一起移**），不要改成"绕轴旋转 5.69°"。
   - 两者都放样 → 可比；一边换螺旋扫掠 → 差 2.7%，那是构造差异。

2. **含圆角的体积**
   - 圆角会占千级 mm³。一边按"外缘倒角在切齿之前、齿根圆角在切齿之后"的顺序补，另一边漏了 → 体积对不上是必然的。
   - 按 SW 特征树的**原顺序**复刻，顺序反了边会选不到（SW 侧）或圆角失败（SolidCraft 侧）。

3. **放样截面**
   - SW 用**顶点序列**做对应。截面草图里多加一条构造线，几何没变但体积差 0.26%（实测 4216 mm³）。
   - SolidCraft 的 `solid.loft` 同样依赖截面曲线顺序：两截面必须是"同一组曲线、同一顺序"。

## 三、容差怎么定

| 对拍对象 | 容差 | 理由 |
|---|---|---|
| 长方体、棱柱 | 1e-9 | 两边都精确 |
| 圆柱、回转体 | **1e-3** | SolidCraft 曲面体积底噪 1e-4 |
| 含浅弧的件 | **1e-2** | 官方：浅弧可到 0.1% |
| 轮廓面积 | **1e-4** | 实测 1.2e-5，是最强判据 |
| 面数 | 精确匹配 | 面数不一致通常意味着构造不同 |

**不要用 1e-5 当判据**：那是工具底噪，不是模型错。

## 四、一次完整的对拍流程

```
1) 从 SW 读：体积、bbox、COM、面数（脚本落成 JSON）
2) 在 SolidCraft 重建同一构造（同一组尺寸、同一顺序、同一种近似手段）
3) 两边各自与【解析解】比一遍，再【互相】比一遍
   —— 只看互相比会掩盖"两边都错"的情况
4) 差异超出上表容差时，先查构造（顺序、圆弧、放样截面），再怀疑内核
5) 结论写清：差多少、差在哪个量、是构造差还是数值差
```

## 五、已跑通的样例（可当回归）

| 项 | SW | SolidCraft | 差 |
|---|---|---|---|
| 4 弧齿槽截面 | 41.4369 mm²（沿弧采样） | 41.4364 mm²（引擎自报） | 1.2×10⁻⁵ |
| 毛坯 d271.3608×60 | 解析 3,470,046.97 | 3,469,827.56 | −6.3×10⁻⁵ |
| 直齿 104 齿整件 | 解析（Cavalieri）3,335,255.72 | 3,331,718.63 | −1.06×10⁻³（含相邻齿槽在齿顶互相咬掉，见下） |

**第三条的 −0.106% 不是纯数值误差**：104 个齿槽在齿顶圆处角宽 0.063 rad > 齿距 0.0604 rad，
相邻槽互相吃掉一点，齿顶被削平 0.035 mm（bbox 径向 135.6457 < 齿顶半径 135.6804）。
**这类"几何本身的耦合效应"必须能从模型算出来，否则不要归因给内核。**
